# go-autodiff

🌐 **[Website](https://go-autodiff.github.io)** · 📚 **[Documentation](https://go-autodiff.github.io/docs/)**

**Automatic differentiation in pure Go. Planned, wave 2 of the go-scikit roadmap.**

**go-autodiff is the planned home of automatic differentiation for go-scikit**: forward and reverse modes, with Jacobian and Hessian helpers that feed `go-numerics/optimize` gradients and the `JacFunc` of `go-numerics/integrate`, both of which take user-supplied derivatives or finite differences today. It is in **wave 2** (PLAN.md item 8).

The organization has no library yet and no release tag: this page, the
[website](https://go-autodiff.github.io) and the
[documentation](https://go-autodiff.github.io/docs/) describe what is planned. The
plan is [PLAN.md](https://github.com/go-scikit/roadmap/blob/main/PLAN.md) and the state of each item is in
[STATUS.md](https://github.com/go-scikit/roadmap/blob/main/STATUS.md) of [go-scikit/roadmap](https://github.com/go-scikit/roadmap).
